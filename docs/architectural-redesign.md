# Architectural reference redesign

The owner supplied two visual references and explicitly allowed a simpler logo. The active design now uses a compact wordmark header, a full-width neutral architectural image, uppercase tracked headings, a centered introduction, an edge-to-edge image/text mosaic, a framed overlapping image panel, a small pale-yellow tool CTA, and a dark four-column footer. The layout is original; no reference branding, photography, placeholder copy, signatures, or source template assets are shipped.

References reviewed: the supplied Pinterest Maison screenshot and the supplied html.design Evonyee screenshot. These are visual direction only.

Active brand assets: `public/assets/wordmark.svg`, `wordmark.png`, and `favicon-modern.svg`. The original `logo.webp` is retained in the repository but no longer used as the active header/publisher mark. The wordmark is original vector typography, not imagegen.

Original instructional content, routes, search, saved-guide controls, recommendations, and the Patio Privacy Planner remain available. Photography-style scenes are disclosed as illustrative AI-created concepts in the editorial policy. Images retain complete compositions; the mosaic uses contain fitting, and mobile images stack without clipping.

All new scene assets below were generated with built-in imagegen, copied into the project, and optimized to WebP. The homepage hero also has an 800-pixel-wide variant. No external template assets or subscriptions were purchased.
