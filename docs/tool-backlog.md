# Practical tool backlog

## Bathroom planner — user idea, 2026-10-14
Reuse the patio planner's interactive placement approach for a bathroom: floor shape/dimensions, walls, movable doors/windows, and draggable fixtures (toilet, sink, shower, bathtub, storage). Show a clear scaled layout. Keep plumbing, waterproofing, electrical zones, accessibility and clearances as explicit future requirements; a visualization cannot approve installation. Start with a simple rectangle before expanding room shapes.

## Balcony and patio tile planner — earlier user idea
Enter floor width/depth and tile dimensions to estimate tile count and show cuts. Account for layout direction, joints and waste; distinguish per-row rounding from area-only arithmetic. Future feature, not yet implemented.
