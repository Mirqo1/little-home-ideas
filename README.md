# Little Home Ideas

Small ideas. Better living.

Content-driven Astro magazine for U.S. readers. Approved logo, original illustrated guides, five categories, and a browser-local Patio Privacy Planner.

- Author articles in `src/content/articles/`.
- Shared design in `src/layouts/`, `src/components/`, and `src/styles/`.
- Build static output with `npm run build`.
- Retain existing GitHub Pages root publishing with `npm run build:pages`.
- Test with `npm test` and `npm run check:site` after building.

See [Publishing](PUBLISHING.md), [Editorial plan](docs/editorial-plan.md), [Audit](docs/audit.md), and [Search, analytics, and hosting](docs/analytics-and-launch.md).

No analytics or advertising scripts are enabled. Hosting and DNS changes require owner approval.
