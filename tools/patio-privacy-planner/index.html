Patio Privacy Planner

Choose a starting approach for more privacy, visualize an example screen layout in 3D, and save a checklist before you buy.

1 Measure your space

Plan one straight boundary. Height is a preference to research, not a safe-height recommendation. Measure from the seating position you want to protect.

2 Choose an approach & check the site

Your priority changes the advice. Wind exposure and balcony permission determine which checks come first. These choices do not change the module count.

3 Compare an example layout

Use an actual product's usable width if known. The default is a paper-layout assumption, not a product recommendation. Supports and overlaps may change fit. Use a decimal point or comma (for example, 2.16 or 2,16).

Optional: estimate using your own prices

Include supports, delivery, or taxes in additional costs. No prices are retrieved from retailers.

What this tool does

It compares starting approaches and calculates straight-line example coverage. It does not select or test products, determine required supports, assess wind or loads, check building codes, or guarantee privacy at a particular height.
