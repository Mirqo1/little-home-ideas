Patio Privacy Planner

Map your patio or balcony, add its roof, walls, railing, and furniture, then compare a privacy-screen layout in 3D.

1 Measure your space

Plan one straight boundary. Screen height is measured from the floor, including when screening starts above a railing. It is a preference to research, not a safe-height recommendation.

A is the far edge in the drawing, C is nearest to you. B is right, D is left. These are drawing labels, not compass directions.

2 Add the existing structure

Shown as a flat roof covering the full area. Adding a roof does not automatically mean a sheltered site.

Existing solid walls

Sides with a railing

This specifies visual coverage, not attachment to the railing. Existing guards and permitted fixing methods need separate checks.

3 Place basic furniture

Enter actual footprints. Furniture is placed near C with example 0.5-ft spacing between pieces, not recommended walking clearance. Check doors and access separately.

4 Choose an approach & check the site

Your priority changes the advice. Wind exposure and balcony permission determine which checks come first. Roof and wall choices do not automatically establish wind shelter.

5 Compare an example layout

Use an actual product's usable width if known. The default is a paper-layout assumption, not a product recommendation. Supports and overlaps may change fit. Use a decimal point or comma (for example, 2.16 or 2,16).

Optional: estimate using your own prices

Include supports, delivery, or taxes in additional costs. No prices are retrieved from retailers.

What this tool does

It visualizes a rectangular space with a full-area flat roof, solid walls, selected railing sides, basic furniture footprints, and one straight screening boundary. It compares starting approaches and calculates example coverage. It does not select or test products, determine required supports, assess wind or loads, check building codes, or guarantee privacy at a particular height.

Read the patio privacy guide or small patio layout guide before making changes.
